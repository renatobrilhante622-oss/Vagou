# Preferência do responsável pelo projeto

Após concluir alterações neste projeto, registre os arquivos em commit e envie ao GitHub usando o remoto existente. Não inclua segredos, arquivos .env reais, caches ou artefatos de build. Não force push nem sobrescreva histórico remoto. Se o envio falhar, preserve o commit local e informe claramente que o GitHub ainda não recebeu as alterações.
